Administración de usuarios

Accesos, permisos, historial de modificaciones, GitHub y respaldos.

Usuarios

Cada usuario recibe un código de acceso personal y crea su propia contraseña en su teléfono o computadora; las contraseñas nunca salen del dispositivo. Operador: registra operaciones y consulta. Consulta: solo lectura. Administrador: acceso completo. Cada registro va firmado digitalmente, por lo que los permisos se verifican en todos los dispositivos.

Almacenamiento en GitHub

Los datos se guardan cifrados en los Issues del repositorio y GitHub conserva todas las versiones. Cada dispositivo guarda además una copia local y funciona sin internet.

Descargue periódicamente un respaldo completo y guárdelo en un lugar seguro.
